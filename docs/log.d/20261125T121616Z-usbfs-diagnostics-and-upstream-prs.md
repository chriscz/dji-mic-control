## 2026-11-25: Unblock usbfs writes, add diagnostics fold, and port upstream PR #3 and PR #4

- **Real-hardware `usbfs` write fix (`LinuxUsbfsTransport`)**: Replaced the synchronous `poll()` loop in the worker isolate (which starved Dart's `commandPort` message loop and left `bulkOut` futures pending indefinitely) with independent `Isolate.run` `USBDEVFS_BULK` (`0xc0185502`) writes on endpoint `0x06` and a 200ms timed `USBDEVFS_BULK` reader loop on `0x86` controlled via a shared native stop flag.
- **Udev trigger and permission log dedup**: Added `--action=add --attr-match=idVendor=2ca3` to `udevadm trigger` so `TAG+="uaccess"` ACLs apply immediately to already-attached receivers, and deduplicated repeated `Permission denied` log warnings per device ID.
- **Diagnostics fold and pending operations strip**: Elevated `TX`, `TX OK (Nms)`, `TX FAIL`, and `Confirmed` logs to `INFO` level, turned `AppLogger` into a `ChangeNotifier`, and added a collapsible bottom `DiagnosticsFold` with a hideable Pending Operations strip.
- **Upstream PR #4 (Mobile Receiver + gain controls, by VaderCheng)**: Ported RX `tag 0x06` unit `0` identification (`DJI Mic Series Mobile Receiver`), `mobile-rx` vector pictogram, `Power: USB` status row, `receiver-gain` (`0x0039`, `-12/-6/0/6/12` dB) and `monitoring-gain` (`0x0026`, `-12..+12` dB) sliders with non-optimistic 3-second confirmation, connected-TX noise cancellation status decoding with read-only `NoiseCancelControl`, and capability write guards blocking unsupported commands.
- **Upstream PR #3 (Simplified Chinese UI localization, by VaderCheng)**: Added pure-Dart `AppStrings` (`en` / `zh-CN` with English fallback) and a persisted Language selector in System & Capabilities Preferences.
